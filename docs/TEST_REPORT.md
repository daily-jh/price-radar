## 명세와 차이 / 미완료

- 추천된 Next.js/FastAPI/PostgreSQL 대신 Node.js·SQLite·순수 JS로 로컬 MVP 구현.
- 공급자 API/라이선스/소비자 데이터 접근 권한은 확보되지 않음. 자동 수집 코드와 외부 발송 없음.
- 별도 수집 워커, 공급원 호출 통계, OAuth/Cloudflare Access/Tailscale 연동, 외부 알림, 조용한 시간, 통화환산 미구현.
- 상세 SKU 필드를 독립 열로 구조화하지 않고 명시적 SKU 문자열로 보관. 옵션 자동 병합 기능 없음.
- 가격 이력은 추가 기록 방식이며 삭제·기존 기록 수정 UI 없음. 오류 관측은 같은 출처/URL/종류/상태/회원조건으로 최신 관측 추가.
- CSV는 검증 대기 기록으로 등록하며 별도 일괄 승인 UI 없음.
- Docker는 설정 파일만 제공. 이 환경에 Docker가 없어 컨테이너 기동 검증하지 않음.
- 암호화 자동 백업, Windows 재부팅 시 자동 실행, 부하 테스트 미실시.
- 인증은 비밀번호 해시와 서버 세션. 서버 재시작 후 세션은 폐기되며 재로그인 필요.
- 인터넷 배포 없음. 로컬 주소는 서버가 실행 중인 동일 컴퓨터에서만 접근.

## 실제 데이터 / 비용 / 다음 단계

실제 판매 가격 사용 없음. 가상 상품을 seed하며 실제 사용은 수동 입력만 지원. 코드 제작 과정에서 서버·API·도메인을 구매하지 않음. 실행 후 `start-private.cmd`에서 본인만 아는 비밀번호를 설정하고 수동 운영으로 전환하세요.
