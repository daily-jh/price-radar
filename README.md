# PRICE RADAR

개인용 가격 관측 웹앱. **구현 범위: 로컬 MVP / 자동 가격 수집 미연동 / 인터넷 배포 없음.**

출시가·네이버 최저가·현재 핫딜가를 나란히 보고, 새상품·미개봉·반품 등급별 가격을 비교합니다. 처음에는 가상 데이터로 둘러보고, 로그인 후 수동 운영으로 바꾸어 직접 기록합니다.

## Windows에서 실행

Node.js 24 이상이 필요합니다. 외부 패키지 설치는 필요하지 않습니다.

1. 이 저장소를 내려받거나 `git clone https://github.com/daily-jh/price-radar.git`로 복제합니다.
2. **`start-demo.cmd`**: 가상 상품으로 바로 둘러보기. `http://127.0.0.1:3081`.
3. **`start-private.cmd`**: 처음 한 번 관리자 비밀번호를 두 번 입력합니다. 입력 내용은 화면에 표시되지 않습니다. 이후 `http://127.0.0.1:3082`에서 로그인합니다.
4. 오른쪽 위 **수동 운영** 선택 → 상품 등록 → 가격 등록 → 목표가 설정.

실행 창을 닫으면 서버가 종료됩니다. 개인용 자료는 `data/radar.sqlite`에 저장됩니다. 데모 실행기의 자료는 종료 시 사라집니다. `.env`의 비밀번호 해시와 `data/`는 깃허브에 올리지 않습니다. 실행 중인 포트가 이미 있으면 기존 사이트를 사용하거나 기존 실행 창을 닫으세요.

## 제공 기능

- 대시보드, 특가 탐지, 반품마켓 필터, 상품 검색·정렬
- 고정된 출시가 / 네이버 / 핫딜 비교와 미확보 상태
- 상태별 가격·출처·관측 시각·배송비·확인된 할인·회원 조건
- 7/30/90일 상태별 차트와 접근 가능한 데이터 표
- 적격 관측일 5일 이상일 때 일별 대표값의 30일 중앙값으로 급락 분석
- 상품 상태별 목표가, 앱 내부 알림 및 중복 억제
- CSV 수동 등록, 중복 제거, 행별 오류 보고, JSON 내보내기
- 서버 로그인, 세션 쿠키, CSRF, 보안 헤더, 로그인 시도 제한
- 파일 DB 영속 저장과 SQLite 일관성 백업 도구

## 개발 / 검증

```sh
npm run check
npm test
npm run demo
```

`npm start`는 `.env`를 읽어 서버를 실행합니다. 직접 설정하려면 `.env.example`을 `.env`로 복사하고 `node src/password.mjs`로 비밀번호 해시를 만드세요. 샘플 해시나 기본 비밀번호는 제공하지 않습니다.

## 실제 데이터와 출처

현재 자동으로 가져오는 실제 가격은 **없습니다**. 데모 상품명과 가격은 전부 가상입니다. 실제 가격은 사용자가 확인한 자료를 수동 입력합니다. 입력 URL은 링크로만 보관하며 서버가 해당 페이지를 요청하지 않습니다.

네이버 종료 API나 쿠팡 판매자 API를 소비자 가격 수집용으로 사용하지 않습니다. 공급원 승인과 자격 검토 없이 자동 수집을 추가하지 않습니다. [데이터 출처 확인 문서](docs/DATA_SOURCES.md).

## 구성과 한계

1인 로컬 사용에 맞춰 **Node.js 24 + SQLite + 순수 HTML/CSS/JavaScript**로 구현했습니다. 명세서의 권장 스택(Next.js/FastAPI/PostgreSQL)은 채택하지 않았습니다. 외부 패키지 없이 바로 실행할 수 있도록 단순화했습니다.

이 버전은 모든 명세를 충족하는 운영 완성본이 아닙니다. 공급자 어댑터의 실제 연동, 별도 수집 워커, OAuth/사설망 인증, 외부 메시지 발송, 통화 환산, 옵션 병합 UI, 암호화 자동 백업 및 운영 서버 배포는 남아 있습니다. 세부 현황은 [구현·검수 보고](docs/TEST_REPORT.md)와 [운영 안내](docs/OPERATIONS.md)를 확인하세요.

GitHub Pages는 정적 호스팅이므로 이 서버 앱을 실행하지 않습니다. 공개 저장소에는 코드만 있고 개인 DB는 로컬에 있습니다. 서버 배포를 원하면 [배포 안내](docs/DEPLOYMENT.md)를 따르세요.
