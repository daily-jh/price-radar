# PRICE RADAR 화면 설계

가격 비교표가 주인공인 개인 관측 도구. 전체를 카드로 쪼개지 않고 왼쪽 탐색, 넓은 상품 목록, 상세 비교 작업면으로 구성한다.

- 바탕 #f4f6fa, 표면 #ffffff, 글자 #172c45, 보조 #52647a, 강조 #245edb, 가격 하락 #087b64, 경고 #a45d11.
- 서체: Windows 맑은 고딕과 시스템 sans-serif. 가격은 tabular-nums, 제품명보다 비교 숫자의 읽기 흐름을 우선한다.
- 넓은 화면: 220px 탐색 → 목록/상세. 모바일: 상단 탐색과 단일 열. 표는 가로 스크롤.
- 주목점은 상품 상세의 세 개 비교 기준과 상태별 가격표. 출시가는 현재 판매가와 구분한다.
- 가상 데이터 표식, 관측 시각, 현재 재고 재확인 안내를 항상 노출한다.

초안 검토: 일반 대시보드의 균일한 통계 카드 대신 관측 상태 띠와 실제 비교표를 선택했다. 그림·상품 사진은 가격 검토에 필요하지 않아 사용하지 않는다.
