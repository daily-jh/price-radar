# 접근 보호

- 운영 서버는 유효한 scrypt 비밀번호 해시 없이는 시작하지 않습니다.
- 비밀번호 평문은 저장하지 않으며 세션 토큰은 서버 메모리에만 보관합니다. 8시간 만료, 로그아웃 즉시 폐기, 재시작 시 재로그인.
- 모든 데이터 API에 인증이 적용됩니다. 공개 `/healthz`는 상태만, `/api/session`은 로그인 여부만 반환합니다. 공개 HTML과 JS에는 개인 자료가 없습니다.
- 변경 요청은 동일 Origin, JSON Content-Type, 세션 CSRF 토큰을 검사합니다.
- HTTP는 루프백 실행만 사용합니다. 외부 도메인은 HTTPS와 Secure 쿠키를 강제합니다.
- 출처 URL은 HTTPS·공개 도메인 형식만 받습니다. URL을 서버에서 fetch하지 않으므로 DNS 재바인딩/리다이렉션 기반 SSRF 요청 경로가 없습니다. 자동 수집 추가 시 DNS/IP/redirect 재검증이 필수입니다.
- 입력 문자열은 UI에서 HTML 이스케이프, DB 쿼리는 매개변수 바인딩. 금액·날짜·상태와 요청 크기를 검사합니다.
- 로그인은 주소별 15분에 5회 제한. 1인 로컬 용도이며 인터넷 공격 부하 검증은 하지 않았습니다.
- 데모 미리보기는 루프백 전용, 인메모리 DB, 수동 운영 API 차단. `LOCAL_DEMO`를 인터넷 환경에 사용하지 마세요.

파일에 접근할 수 있는 컴퓨터 계정은 로컬 DB를 읽을 수 있습니다. Windows 계정 보안 및 디스크 암호화가 별도로 필요합니다. `.env`와 DB·백업은 Git 제외 대상입니다. 백업 자체 암호화와 자동 보존 정책은 아직 없습니다.
