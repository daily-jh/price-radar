# PRICE RADAR 온라인 버전

소유자 전용 Sites 호스팅. 로컬 컴퓨터를 켜 두지 않아도 브라우저에서 접속합니다.

## 사용

사이트 소유자 계정으로 로그인한 뒤 오른쪽 위 **수동 운영**을 선택합니다. 상품 등록 → 가격 관측 등록 → 목표가 설정 순서로 사용합니다. 처음의 데모 상품과 가격은 모두 가상입니다. 온라인 저장소는 처음에는 비어 있으며 기존 컴퓨터의 DB는 자동 이전하지 않습니다.

## 저장과 인증

- Sites의 소유자 전용 접근 제어와 계정 로그인을 사용합니다. 기존 로컬 비밀번호는 온라인에 전송하거나 복사하지 않습니다.
- 모든 데이터 API는 인증을 검사하며, DB는 로그인 사용자 ID와 DEMO/MANUAL 모드별로 분리합니다.
- 가격·관심 규칙·알림은 D1에 저장합니다. 다른 기기에서도 같은 계정으로 조회합니다.
- 여러 창의 동시 저장은 버전 비교로 충돌을 거부하여 기록 유실을 방지합니다. 충돌 시 새로고침 후 저장하세요.
- 쓰기 요청은 동일 출처 및 JSON과 전용 요청 헤더를 요구합니다. 데이터 API 응답은 no-store입니다.
- 데이터 모드별 스냅샷은 1.8MB 및 관측 5,000개로 제한합니다. 더 큰 규모에는 정규화된 테이블로 전환이 필요합니다.
- 설정에서 JSON으로 내보내어 개인 사본을 보관할 수 있습니다.

## 현재 범위

가격 비교, 상태별 차트, 상품/관측 등록, 목표가, 앱 내부 알림, CSV 등록, 내보내기를 지원합니다. 자동 가격 수집·외부 메시지 발송은 미연동입니다. 알림은 관측/규칙/설정 변경 시 평가하며 별도의 예약 수집 작업은 없습니다. 오래된 데모 가격은 현재가에서 제외됩니다.

## 개발

Node.js 24 이상. Sites 제공 Vinext 빌드·인증·D1 연결을 사용합니다. `npm run dev`의 로컬 시뮬레이션 로그인은 운영 빌드에 포함되지 않습니다. `npm run db:generate`로 스키마 마이그레이션을 생성합니다. 실제 호스팅은 Sites 배포 도구로 합니다.

## 검증

- 온라인 저장 재조회와 사용자 분리, 동시 쓰기 충돌 방지, 데모/수동 분리, 알림 중복 방지 자동 테스트 4개 통과.
- 기존 로컬 버전의 가격 계산·보안 테스트 25개를 통과한 계산 로직을 재사용.
- 온라인용 빌드 및 로컬 D1 마이그레이션 성공.
- 로컬 브라우저에서 온라인 저장 대시보드와 수동 운영 화면 확인.

소스에는 사용자 DB·비밀번호·토큰을 포함하지 않습니다. `.wrangler`, `.sites-runtime`, `.env`는 Git 제외 대상입니다.
